2전체 구조

판단은 ESP32가 한다. 인터넷이 끊겨도 집 안 부저는 울려야 하기 때문이다. Firebase와 웹은 가족에게 알리는 길이다.

PIR 조절 (시연용)

  • 뒷면 주황색 나사 두 개: Tx(시간)를 반시계 끝까지 돌려 가장 짧게(약 3초). Sx(감도)는 가운데에서 시작해 1~2m 에서 반응하게 맞춘다.
  • 점퍼가 있으면 H(반복) 쪽에 둔다. 움직이는 동안 계속 HIGH 가 나온다.
  • 센서 앞 반구가 사람 쪽을 향하게. 노트북 화면이나 사람 많은 쪽을 향하면 계속 감지된다.

약통 적외선 센서 조절

  • 약통 바닥(안쪽)에 센서를 붙여 뚜껑을 위로 본다. 뚜껑을 닫으면 센서 LED 가 켜지고(물체 있음 = LOW), 열면 꺼져야 한다(= HIGH).
  • 파란 나사로 감도를 맞춘다. 뚜껑 닫힘에서만 LED 가 켜질 때까지 돌린다.
  • 반대로 동작하면 ESP32 코드의 MED_OPEN_IS_HIGH 를 false 로 바꾼다.

4집 모형

종이 상자 하나를 방 세 칸으로 나눈다. 센서는 실제 집에 붙일 자리에 붙인다. 심사위원이 한눈에 알아보게 방 이름을 크게 쓴다.

  • 목걸이: 마이크로비트 + AAA 배터리 소켓을 작은 종이 케이스에 넣고 끈을 단다. 시연에서 떨어뜨리니 고무줄로 단단히 묶는다.
  • [괜찮아요] 버튼은 어르신이 바로 누를 수 있게 크게 만든다(병뚜껑을 버튼 위에 붙이면 누르기 쉽다).
  • 선은 상자 바닥 아래로 돌려 빵판까지 모은다. 선마다 마스킹 테이프로 이름표(PIR, SOS…)를 붙이면 고칠 때 빠르다.

5마이크로비트 코드

마이크로비트 두 개에 서로 다른 코드를 올린다. 무선 그룹 번호 77 이 둘이 같아야 한다. 다른 팀과 겹치면 둘 다 같은 다른 번호로 바꾼다.

  1. 크롬에서 makecode.microbit.org → 새 프로젝트.
  2. 위쪽 JavaScript 탭 → 있는 코드를 전부 지우고 아래 코드를 붙여넣는다.
  3. 마이크로비트를 USB로 꽂고 다운로드(처음이면 "연결" 창에서 기기 선택).
  4. 목걸이용과 받는 쪽용을 각각 올린다. 올린 마이크로비트에 마스킹 테이프로 이름을 적는다.

낙상을 어떻게 판단하나 (보고서 3장 알고리즘)

  1. 자유낙하: 가속도 크기가 평소(약 1000mg)에서 500mg 아래로 떨어진다. 몸이 잠깐 붕 뜬 상태다.
  2. 충격: 그 뒤 0.8초 안에 2500mg 넘는 충격. 바닥에 부딪힌 순간이다.
  3. 정지: 그 뒤 1.5초 동안 80% 이상이 거의 안 움직인다(800~1250mg). 쓰러져 있다.

셋이 모두 맞을 때만 낙상으로 본다. 앉기·걷기는 1번이 없고, 넘어졌다 바로 일어나면 3번이 없다. 그래도 남는 잘못된 경보는 ESP32의 10초 [괜찮아요]가 한 번 더 거른다.

{{PENDANT}}
받는 쪽 마이크로비트 firmware/microbit/receiver.ts
{{RECEIVER}}
먼저 버튼으로 확인두 마이크로비트 모두 A 버튼이 "낙상 신호 바로 보내기"다. 목걸이 A → 받는 쪽 화면이 ✗ 로 바뀌면 무선 성공. 받는 쪽 A → ESP32가 1초마다 삑 하면 배선 성공.

6ESP32 코드

판단 규칙은 전부 이 파일 안에 있다. 맨 위 "여기만 바꾼다" 부분의 와이파이 이름·비밀번호만 바꾸면 된다.

  1. 폰 핫스팟을 2.4GHz 로 켠다. 아이폰: 설정 → 개인용 핫스팟 → 호환성 최대화 켜기. 안드로이드: 핫스팟 → 대역 2.4GHz.
  2. Arduino IDE → 설정 → 추가 보드 관리자 URL 에 https://espressif.github.io/arduino-esp32/package_esp32_index.json → 보드 매니저에서 esp32 (Espressif) 설치.
  3. 도구 → 보드: ESP32 Dev Module, 포트: /dev/cu.usbserial-… 또는 cu.wchusbserial….
  4. 아래 코드를 붙여넣고 WIFI_SSID, WIFI_PASS 를 바꾼 뒤 업로드.
  5. 시리얼 모니터를 115200 으로 열어 와이파이 연결 중... 연결됨, 곁에 시작 이 나오는지 본다.
업로드가 "Connecting....___" 에서 멈추면보드의 BOOT 버튼을 누른 채로 업로드를 다시 누르고, "Writing" 이 뜨면 뗀다.

7하나씩 확인

가족 화면을 폰으로 열어 두고 위에서부터 하나씩. 되면 체크한다(이 폰에만 저장된다). 안 되면 다음으로 넘어가지 말고 10 안 될 때를 본다.

81분 시연

  1. 심사위원 폰으로 QR → 가족 화면. "베트남에 있는 우리가 서울 할머니를 보는 화면입니다."
  2. 집 모형 앞에서 손 흔들기 → "마지막 활동: 방금".
  3. 가만히 30초(그동안 약통 설명) → 노랑 → 빨강, 폰이 울린다 → [확인했어요] → 부저 꺼짐.
  4. 약통 열기 → 아침 ✓.
  5. 목걸이 떨어뜨리기 → 카운트다운 → 경보. "괜찮으시면 10초 안에 버튼 하나로 취소됩니다."
  6. SOS 버튼 → 폰이 바로 빨개진다. 마지막에 아래 "어떻게 작동하나요" 그림을 보여 준다.
기기가 안 될 때주소 끝에 ?demo 를 붙인 시연용 화면을 연다. 같은 흐름을 화면 버튼으로 보여 줄 수 있다. 실제 기기 영상은 미리 찍어 둔다.
